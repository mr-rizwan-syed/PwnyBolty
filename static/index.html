ClickForClickOnce

Welcome to ClickForClickOnce - an easy, web-based ClickOnce which allows operators to generate configurable clickonce payloads. Checkout the Github repository to read more about the project, how it works, IoCs and more!

ClickOnce Name

This would be the name of the application the user sees. Make sure it fits the ruse!

AppDomainManager Injection Options

The clickonce uses AppDomainManager Injection to run payloads - choose which Exe would you like to run your payload.

tzsync
Tzsync is a TimeZone Sync program responsible for synchronizing time zone information on a Windows operating system. Note that this is a console application so you might see a CMD terminal pop up.
Powershell ISE
The Windows PowerShell Integrated Scripting Environment (ISE) is a host application for Windows PowerShell that provides a graphical user interface for running commands, writing, testing, and debugging scripts.
ServiceHub.Host.netfx
ServiceHub.Host.netfx.x64 is associated with Visual Studio's Service Hub, which is a set of background services that provide support for various Visual Studio features and tools.
PerfWatson2
PerfWatson2 is a part of Microsoft Visual Studio and is related to performance monitoring and crash reporting while it's running.
